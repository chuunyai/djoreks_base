│   ├── main.tex            # Рабочий файл отчета для наглядности

├── .gitignore              # Исключения для Git

### Регламент

1. **Именование файлов.** Запрещено заливать файлы с дефолтными именами (`IMG_1234.jpg`, `video_2026.mp4`). Формат имени: `ГГГГ-ММ-ДД_краткое_описание.расширение` (например: `2026-11-16_discord_incident.mp4`).
2. **Лимит по весу.** Файлы тяжелее **25 МБ** не заливать в основную ветку — использовать вкладку **Releases**.
3. **Формат коммитов.** Писать кратко и по сути:
   * `add:` — добавление нового файла (`add: screenshot from voice chat`)
   * `fix:` — замазывание личных данных или замена файла (`fix: blur sensitive info`)
   * `docs:` — обновление текста и правил

### Инструкиця по LaTeX и отчетам

1. Зайдите на overleaf.com, создайте проект.
2. Войдите в аккаунт и нажмите `New Project` (Новый проект) → `add file from zip` или пустой проект.
3. Загрузите зип файл целиком или класс `sfureport.cls` (значок загрузки Uploda). 

#### Смените компилятор (важно).
4. Наш класс требует `XeLaTeX` или `LuaLaTeX`: Нажмите значок шестиренки (слева снизу).
5. В пункте Compiler выберите `XeLaTeX` (по умолчанию стоит pdfLaTeX, с ним проект выдаст ошибку).
6. Оформите `main.tex`. 
 Откройте файл `main.tex` в левой панели, удалите стандартный шаблон и вставьте минимальный каркас документа:

```bash
\documentclass{sfureport}

% Данные для титульного листа
\institute{Институт космических и информационных технологий}
\department{Кафедра вычислительной техники}
\worktype{Отчёт по лабораторной работе № 1}
\discipline{программированию}
\title{Разработка алгоритмов сортировки}
\author{И. И. Иванов}
\studentgroup{КИ24-15Б, 24150001}
\teacher{П. П. Петров}

\begin{document}

\maketitle
\stutoc

\structsection{Введение}
Текст введения с автоматическим абзацным отступом.

\section{Первый раздел}
Основной текст отчёта.

\structsection{Заключение}
Выводы по проделанной работе.

\end{document}
```
Также доступен готовый вариант с разнообразными примерами (в том числе листинг кода)
