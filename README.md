### Регламент

1. **Именование файлов.** Запрещено заливать файлы с дефолтными именами с камер и мессенджеров (`IMG_1234.jpg`, `video_2026.mp4`). Имя должно отражать суть и дату, например: `2026-11-16_incident.mp4`.
2. **Лимит по весу.** Видео и архивы тяжелее 25 МБ не пушить в основную ветку. Для тяжелых файлов использовать вкладку **Releases**.
3. **Коммиты.** Писать по делу, чтобы по истории было понятно, что добавлено:
   * `add:` — новый файл, цитата или скриншот (`add: screenshot from discord`)
   * `fix:` — цензура личных данных, обрезка или замена файла (`fix: blur personal info`)
   * `docs:` — правки в README и описаниях
